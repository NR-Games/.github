# Contributing

NR Games repositories are maintained by the NR Games team. Outside contributions are accepted by invitation.

## Reporting a bug

Open an issue in the repository with the bug form, or write to rybak.nekyadnex.ru@gmail.com.
Security problems go only by email — see [SECURITY.md](SECURITY.md).

## Pull requests (invited contributors)

- One change per pull request, with tests for the changed code.
- Conventional commit messages: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
- Sign off every commit (`git commit -s`); the organization requires it.
- Never commit secrets, keys, keystores or store credentials.
