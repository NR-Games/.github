## How we build

- **Offline first.** Every game plays without an account or a connection.
- **Small and fast.** Native code where it counts, no heavy engines for simple games.
- **Fair.** No pay-to-win: purchases remove ads or add content, never skip the puzzle.
- **One quality bar.** Every screen is checked in all languages before release.
