## How we build

- **Offline first** - every game plays without an account or a connection
- **Small and fast** - compact downloads, quick starts, tested on real devices
- **Fair** - no pay-to-win: purchases remove ads or add content, never skip the puzzle
- **For everyone** - many languages, accessibility and right-to-left layouts from day one
